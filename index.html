Backend Customer Data Linker / 2026

The Identity Reconciliation Service is an automated backend API that identifies and consolidates customer identities across varying email and phone combinations. Built with Node.js, Express, and Prisma ORM, it exposes a POST /identify endpoint that intelligently processes incoming contacts. It maintains primary and secondary relationships, and safely merges conflicting identities using database transactions to ensure data consistency.

Tools Used: Node.js, Express, Prisma ORM, SQLite, Jest

Built using Node.js, Express, Prisma ORM, and SQLite, the service exposes a POST /identify API that analyzes incoming contact information and handles new identities, exact matches, partial matches, and conflicts between previously separate customer groups.

The system maintains primary and secondary contacts, automatically merges conflicting identities by keeping the older primary record, and re-links associated secondary contacts. Database transactions are used during merges to ensure data consistency.

Key Highlights:
  • Automated customer identity reconciliation
  • Primary/secondary contact relationship management
  • Handling of new, exact, partial, and merge scenarios
  • Transaction-safe database operations
  • REST API using Express & Prisma
  • Jest unit tests covering core business cases

Kalman Filter Multi-Object Tracking

This project is a real-time object tracking system that can detect and keep track of multiple objects across video frames.

A YOLOv8 model first detects objects in each frame. The system then uses a Kalman Filter to predict where each object will move in the next frame, even when the detection is noisy or temporarily missing.

To make sure each detection is matched to the correct existing object, the tracker uses IoU (Intersection over Union) to measure how closely bounding boxes overlap and the Hungarian Algorithm to find the best matches.

The system continuously follows a simple cycle:
Detect → Predict → Match → Update → Track

When a new object appears, a new track is created. When an object temporarily disappears, the Kalman Filter continues predicting its position. If it remains missing for too long, its track is removed.

The project also benchmarks the Kalman Filter against the One Euro Filter to compare how well they handle noisy measurements, jitter, and missed detections.

Overall, the project demonstrates how computer vision, probability, linear algebra, and real-time tracking can be combined to build a multi-object tracker from the ground up.
